**Första produktionsklara versionen** av automatisk rapportgenerator för LIA-bedömningar.

- 🔧 **Flexibel Excel-läsare** - Anpassar sig automatiskt till olika format (Q1-Q30, Q1-Q34, etc.)

## 📦 Installation

### 🎯 För lärare (Rekommenderat)
1. **Ladda ner** `LIA_Rapportgenerator.exe` nedan
2. **Dubbelklicka** på exe-filen för att starta
3. **Färdig!** - Inga installationer behövs

### 💻 För utvecklare
1. **Klona** repository eller ladda ner källkod
2. **Installera** Python 3.8+ och beroenden: `pip install -r requirements.txt`
3. **Kör** med: `python main.py`

- **Windows 10/11** (64-bit)
